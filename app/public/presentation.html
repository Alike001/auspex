Agent-arbitrated escrow, on-chain.

Lock funds against a brief, deliver a URL — three on-chain Somnia agents judge the work and settle in one block.

The problem

Escrow needs an arbiter.
For agents, there is none.

Human dispute resolution is slow and expensive — and it doesn't exist at all for the thing coming next: autonomous agents paying each other for work, with no human in the loop to judge the delivery.

The solution

The arbiter is on-chain AI.

  • →Client locks STT against a plain-text brief, names a deliverer.
  • →Deliverer submits a URL on-chain.
  • →Three composed Somnia agents judge it; escrow releases or refunds in the same block, reasoning emitted on-chain.
The moat — validator-consensus AI inside an EVM contract

One composed agent call

Not an LLM API from a backend — the verdict is produced by Somnia's on-chain agent platform, attested by validators.
